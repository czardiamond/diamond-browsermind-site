FROM PLAYGROUND TO LIVE AGENT

Connect the real browser.

The tutorial uses a Python server, Google ADK, Gemini Live and a Chrome debugging connection. A static hosted page cannot control other tabs on its own.

  1. Download the local project bundle and follow its README.
  2. Start a separate Chrome profile with remote debugging and the browser-harness daemon.
  3. Supply your own Gemini key privately in the local backend’s .env. Never paste it here.
  4. Run the Python backend, then open http://127.0.0.1:8080/ui/ and select Connect local agent.

Live mode sends your microphone audio and browser screenshots to Google. Use a disposable browser profile without sensitive accounts. The source agent is experimental; don’t use it for payments or irreversible actions.

The public playground uses deterministic commands, not an AI model. Local live integration is included but requires your own setup and has not been tested end to end with a paid API session.
